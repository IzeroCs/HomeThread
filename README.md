# Namorix Thread

Monorepo cho Thread dashboard/plugin gồm:

- `backend/` — Node.js + TCP frame protocol + CoAP ingest
- `frontend/` — Lit + Vite
- `shared/` — types/events/constants dùng chung

## Quick Start

```bash
npm install
npm run dev
```

Chạy riêng:

- `npm run dev:backend`
- `npm run dev:frontend`

Build:

- `npm run build`
- `npm run build:plugin`
- `npm run build:plugin:watch`
